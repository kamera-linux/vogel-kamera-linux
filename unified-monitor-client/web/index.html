❓ Online-Hilfe – Vogel-Kamera

Übersicht

Diese Oberfläche steuert den Vogel-Kamera-Daemon auf dem Raspberry Pi. Alle Aktionen werden direkt per HTTPS-API ausgeführt. Das Dashboard aktualisiert sich automatisch alle 5 Sekunden.

🔴 Detection starten / stoppen

Startet oder stoppt die KI-Bewegungserkennung (YOLO / Hailo). Wird eine Bewegung erkannt, beginnt automatisch eine Aufnahme.

⏺ Manuelle Aufnahme

  • Dauer – Aufnahmelänge in Sekunden (Schieberegler)
  • Auflösung – HD / Full-HD / 4K
  • Die Aufnahme startet sofort und erzeugt eine .h264-Rohdatei.

🔄 Konvertieren

Konvertiert alle vorhandenen .h264-Rohdateien in das abspielbare .mp4-Format (via ffmpeg). Anschließend werden die MP4s automatisch an alle aktiven Sync-Ziele übertragen.

  • Die Zahl im gelben Badge zeigt die Anzahl noch nicht konvertierter H264-Dateien.
  • Die Konvertierung läuft auch automatisch alle 3 Minuten im Hintergrund – ohne Button-Klick.

📤 Alle übertragen (SSH)

Überträgt alle fertigen .mp4-Dateien per rsync über SSH an alle konfigurierten und aktiven Sync-Ziele – ohne erneute Konvertierung. Nützlich wenn ein früherer Transfer fehlgeschlagen ist.

⚙ Sync-Ziele konfigurieren

Unter ⚙ Einstellungen können beliebig viele SSH-Ziele eingerichtet werden:

  • Host / IP – Hostname oder IP-Adresse des Zielrechners
  • SSH Benutzer – Benutzername auf dem Zielsystem
  • Ziel-Pfad – Verzeichnis auf dem Zielrechner, z. B. /home/roimme/Videos/
  • SSH Private Key – Privaten Schlüssel einfügen (OpenSSH-Format). Einmal gespeichert, muss er nicht erneut eingegeben werden.
  • Mit 🔌 Testen die Verbindung prüfen, bevor gespeichert wird.
  • Mehrere Ziele möglich – z. B. NAS + Laptop gleichzeitig.

Der SSH-Key wird sicher im Container unter /config/sync_key_N gespeichert und verlässt den Pi nicht.

📋 Aufnahmen-Tabelle

  • ⬇ Download – MP4 direkt im Browser herunterladen
  • 🗑 Löschen – MP4 und zugehörige H264-Quelldatei nach Bestätigung dauerhaft löschen

🔐 Sicherheit

  • Login erfordert Passwort + 2FA-Code (TOTP) – kompatibel mit Google Authenticator, Aegis, Bitwarden u. a.
  • Alle API-Aufrufe sind Bearer-Token-geschützt. Das Token ist nur für diese Browser-Session gültig.
  • Die Verbindung ist per TLS (HTTPS, selbstsigniertes Zertifikat) verschlüsselt.
