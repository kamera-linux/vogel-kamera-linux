## 📋 Vortragsinhalte

Der Vortrag behandelt die Entwicklung und den praktischen Einsatz einer automatisierten Vogelbeobachtungsstation mit:

- 🐧 **Raspberry Pi** als Hardwareplattform
- 🐍 **Python** für die Programmierung
- 🤖 **Künstliche Intelligenz** für Vogelerkennung und automatische Klassifikation
- 📸 **libcamera** für Kamerasteuerung und Bilderfassung
- 🎵 **Audio-Aufnahme** und -Analyse für Vogelrufe
- 📊 **Datenverarbeitung und -speicherung** für langfristige Beobachtungen
- 🌳 **Citizen Science** und Naturschutz-Anwendungen

## 🛠 Technischer Stack

- Raspberry Pi (empfohlen: Pi 5)
- Python 3.12+
- OpenCV für Bildverarbeitung
- TensorFlow/PyTorch für KI-Modelle
- libcamera für native Kamerasteuerung
- Audio-Aufnahme für Vogelrufe
- Git & GitHub für Versionskontrolle
